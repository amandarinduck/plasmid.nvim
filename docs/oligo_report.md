# Oligo structure estimates vs primer3 (thal)

## Summary

* `lua/plasmid/bio/oligo.lua` is **not** equal to primer3 and does not claim to be. Over 3928 single oligos and 3600 pairs, dG (kcal/mol, 37 °C) correlates with primer3 at Pearson r = 0.955 (hairpin), 0.992 (self-dimer) and 0.982 (heterodimer); median absolute error 0.39 / 0.41 / 0.39, 95th percentile 1.71 / 1.58 / 1.09.
* Warning agreement (same flag as primer3): hairpin dG < -2: 95.6%; self-dimer dG < -9: 97.4%; heterodimer dG < -9: 99.1%; 3'-anchored dimer dG < -5: 98.1% (self) / 99.0% (pair); hairpin Tm > 47 °C: 93.0%.
* 3' end stability (primer3's PRIMER_..._END_STABILITY, the pentamer duplex dG) is reproduced exactly (max abs error 0.000 kcal/mol over 3928 oligos).
* primer3 reports *no* hairpin for 1114 oligos where this module returns its best (weak) fold; those folds have dG between -1.74 and +2.85 kcal/mol (median +1.03), i.e. none would trigger the -2 kcal/mol warning. Tables below count 'no structure' as dG 0.
* Structure Tm is the weakest output: both programs report Tm of *their* chosen structure, primer3 tends to pick longer, loopier structures with larger |dH| (see below), so Tm differs by a median of 2.9 °C (self-dimer, primer3 Tm > 0 °C) with a long tail. Use dG for decisions; Tm is indicative.
* Why they differ: the duplex bookkeeping (stacks, initiation, terminal A·T, salt, Tm formula) matches primer3 exactly apart from the AA/TT stack (SantaLucia & Hicks 2004 here, 1998 in primer3); on identical contiguous helices with terminal mismatches at both ends the residual is entirely explained by different terminal-mismatch tables; the rest comes from choosing a different structure (this module minimises dG at 37 °C exactly within its structure class; primer3's choice differs, sometimes finding a less stable structure, sometimes a more stable one under its own parameters).

## Model and approximations

Two-state nearest-neighbour model, implemented from published tables (no primer3 code was used; primer3 is only called as an oracle in this script): SantaLucia & Hicks 2004 Watson–Crick stacks, initiation and terminal A·T penalty; single internal mismatches (Allawi & SantaLucia 1997–98, Peyret et al. 1999), terminal mismatches (SantaLucia & Peyret 2001) and dangling ends (Bommarito et al. 2000), all as tabulated in Biopython `Bio.SeqUtils.MeltingTemp`; SantaLucia & Hicks 2004 loop initiation for hairpin / bulge / internal loops (entropic, Jacobson–Stockmayer extrapolation), +0.3 kcal/mol per nt internal-loop asymmetry; salt as 0.368·ln[Na+eq] per stack with [Na+eq] = [Na+] + 120·sqrt([Mg2+] − [dNTP]) (von Ahsen 2001). Exact dynamic programming over one duplex (dimers) or consecutive stem-loops (hairpin folds) with stacks, 1x1 mismatches, bulges and internal loops up to 30 unpaired nt, terminal mismatches / dangling ends at helix ends; the minimum-dG structure at the requested temperature is reported. Approximated or omitted: tri-/tetraloop bonus tables, hairpin-specific terminal-mismatch table (duplex values used), internal-loop first-mismatch bonuses (terminal-mismatch values at both closing pairs used instead), tandem-mismatch table (scored as 2x2 internal loops), multibranch loops, G·T as helix pairs, symmetry correction.

Parameter note: Biopython's DNA_TMM1 lists terminal mismatch GG/CG as dH -0.7, dS -19.2 (dG37 +5.25, while every other entry is -0.1 to -1.5 kcal/mol). Read literally it forbids any C·G pair flanked by a G/G mismatch (it made 14- and 16-bp palindromes pair only 12/14 bp). We assume a decimal slip in dH and use -7.0 (dG37 -1.05); primer3's implied value for that motif is about -1.2. This changed self-dimer warning agreement by about 0.3 percentage points.

Development note (not reproduced by this script; the code path was removed): a variant that picked, at every DP cell, the partial structure with the highest Tm instead of the lowest dG agreed less well with primer3 (threshold agreement hairpin 93.9%, self-dimer 92.0%, heterodimer 97.5%, versus 95.9%, 97.1%, 99.1% for minimum dG at the same stage of development), so minimum dG is used.

Generated by `tests/tools/oligo_oracle.py` (primer3-py 2.3.1, Lua: LuaJIT 2.1.1774638290). Conditions: Na+ 50 mM, Mg2+ 1.5 mM, dNTP 0.6 mM, oligo 50 nM, dG at 37 °C (primer3-py `calc_*` defaults, max_loop 30).

## Where the differences come from

**Same structure or not.** Pairs parsed from primer3's ASCII structure and compared with the Lua base pairs (cases where both report a structure):

| structure | n | identical pairs | median / p95 abs dG err (identical) | median / p95 abs dG err (different) | Lua more stable when different |
|---|---|---|---|---|---|
| hairpin | 2798 | 67.2% | 0.06 / 1.21 | 0.54 / 1.88 | 56% |
| homodimer | 3912 | 75.8% | 0.34 / 1.58 | 0.55 / 1.64 | 43% |
| heterodimer | 3600 | 68.6% | 0.38 / 1.07 | 0.41 / 1.11 | 30% |

**Stacks, initiation, terminal A·T, salt and Tm formula.** On the 150 perfect palindromes, both programs pair the full length; after removing 0.3 kcal/mol dH and 0.9 cal/(K·mol) dS per AA/TT stack (SantaLucia & Hicks 2004 AA/TT = -7.6/-21.3, which this module uses as specified; primer3's values match the 1998 unified -7.9/-22.2; dG37 is -1.00 in both) the residual is at most 2.3e-14 kcal/mol in dH and 2e-11 cal/(K·mol) in dS. The duplex bookkeeping (initiation, terminal A·T penalty, 0.368·ln[Na+] per stack with Na+ = mv + 120·sqrt(Mg − dNTP), Tm = dH/(dS + R ln Ct) for self-dimers) therefore matches.

**Terminal mismatches.** For 1217 self-dimers where both programs choose the same contiguous helix with a terminal mismatch at each end, the dG difference has SD 0.59 kcal/mol; one least-squares offset per terminal-mismatch motif (48 motifs) leaves a residual SD of 0.000 kcal/mol. The remaining dimer error on identical structures is therefore a parameter-table difference (this module: SantaLucia & Peyret 2001 terminal mismatches as tabulated in Biopython; primer3 ships its own tables), not a search or bookkeeping difference. Motifs whose implied offset is at least 0.4 kcal/mol (Lua − primer3, n ≥ 10): CG/GA -0.62 (n=26), AG/TT -0.42 (n=21), CG/GT -0.41 (n=37), TG/AT +0.54 (n=57), TT/AT +0.58 (n=81), GA/CC +0.66 (n=54), GA/CG +0.79 (n=57), TG/AG +0.82 (n=26), GA/CA +0.87 (n=139).

## Performance (Neovim, LuaJIT)

Batch: 3928 single-oligo `assess()` calls in 3207 ms (0.82 ms each, includes hairpin + homodimer + 3'-anchored self-dimer); 3600 pairs (heterodimer + 3'-anchored heterodimer) in 2656 ms (0.74 ms each).  
Full 25-mer pair (2 hairpins, 2 homodimers, heterodimer, 4 3'-anchored dimers), 200 pairs: median 3.25 ms, 95th pct 6.31 ms, max 17.35 ms.  
Same pairs as a user-level pair check (`assess(a)`, `assess(b)`, `heterodimer(a, b)`, `end_dimer(a, b)`, `end_dimer(b, a)`; assess includes GC/runs/end stability and warnings): median 2.43 ms, 95th pct 4.70 ms, max 14.39 ms.  
Timings are wall-clock from one run after a JIT warm-up pass on this machine (12-core x86_64 workstation).  
primer3-py (C) for the whole oracle pass: 8.4 s.
