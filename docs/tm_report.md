## Findings and decisions

1. **The NN model, the salt corrections and the conc/4 Phusion convention in polymerase-tm match NEB exactly.** With NEB's own buffer salts every integer Tm the API returned is reproduced, and long-format unrounded Tms agree to floating-point precision.
2. **Four NEB buffer salts differ from polymerase-tm's table.** Each product's Tms fit exactly one integer salt (1.0–500.0 mM scanned in 0.1 mM steps; the fit window is ≤ 1 mM wide and contains exactly one integer). NEB API v0.19.0 uses standard Taq / Crimson Taq 55 mM (polymerase-tm 51), OneTaq Standard 54 (51), OneTaq GC 80 (51), and Q5U 170 (180). The rest agree: Q5 150, Phusion 222, LongAmp 100, ThermoPol 40, Hemo KlenTaq 70, Multiplex 90. In default mode `M.BUFFERS` holds the NEB values; `M.BUFFERS_PTM` and `compat = "polymerase-tm"` keep polymerase-tm's. Over the bulk set the integer Tm differs from polymerase-tm in 69,941 of 116,702 cases with a changed salt, and in 0 of 284,144 cases with an unchanged salt.
3. **NEB computes Ta from the unrounded lower Tm, not from the integer Tms.** The rule and cap are applied to the unrounded value, the result is rounded to 0.1 °C (the value the long format reports, e.g. Q5 `ta: 63.3`), and that is rounded to an integer. Example (NEB batch, Q5): Tm1 63, Tm2 75, Ta 65, not 64. The unrounded lower Tm is 63.465; 64.465 → 64.5 → 65. Default mode does this. Over the bulk set it changes Ta relative to polymerase-tm in 43,135 of 111,628 cases (this count includes the salt changes and DMSO ties).
4. **Rounding: NEB rounds half up, and the reported Tm is rounded once.** Integer Tms equal round(unrounded Tm) in all 5,940 values. Truncation and one-decimal pre-rounding of the Tm are both contradicted by the data. Exact .5 ties arise in the 0.1 °C Ta step, e.g. 64.5 → 65 and 40.5 → 41 (Taq: 45.5 − 5). They always go up, which is JavaScript `Math.round` semantics and not Python's round-half-to-even. tm.lua therefore rounds half up (`floor(x)+1 if x − floor(x) ≥ 0.5`). polymerase-tm uses Python `round()`, which differs only at exact ties; in polymerase-tm those ties come from DMSO, e.g. 2.5 % → −1.5 °C. Compat mode reproduces half-to-even. Residual uncertainty: whether NEB's 0.1 °C step is `Math.round(x*10)/10` or `toFixed(1)` cannot be distinguished; they differ only for values within ~1e-14 of a binary .x5 boundary.
5. **Uncapped Ta for Crimson Taq, Multiplex and Q5U.** For ctaq-0, multiplex-0 and q5u-0 the API returns Ta = lower Tm with no offset and no cap: 240 pairs, maximum Ta 106 °C. The same happens for ctaq-1, taqmaster-0/1, taqquickload-0 and taqpcrkit-0. A Ta above 100 °C is not a usable recommendation, so the API probably has no Ta rule for these codes. tm.lua keeps polymerase-tm's rules (from the NEB web calculator): Crimson Taq and Multiplex −5 °C, cap 68; Q5U +2 °C, cap 72. These Ta values are excluded from the NEB Ta comparison and listed separately. Tm for these products is compared and matches.
6. **The long-format endpoint divides the Phusion concentration by 4 twice.** `POST /tm` with fmt=long for phusion-*/phusionflex-* echoes `conc: 0.125` for 0.5 µM sent, and its Tms correspond to 31.25 nM. `POST /tm/batch` uses 125 nM, a single division, consistent with polymerase-tm and NEB's stated convention. tm.lua follows batch. The long-format comparison evaluates Lua at the echoed concentration, which reproduces NEB to 1e-13 °C and confirms the double division.
7. **polymerase-tm's `owczarzy_bivariate()` is not the published Owczarzy 2008 equation in the mixed regime (0.22 ≤ √[Mg²⁺]/[Na⁺] < 6).** It omits the [Na⁺]-dependent coefficients a, d and g (eqs. 18–20). tm.lua implements the published form and matches Biopython saltcorr = 7 to 2.8e-13 °C. Against polymerase-tm `calc_sdm_tm()` it agrees in the other regimes (max |Δ| 1.7e-13 °C) and differs by up to 4.84 °C in this one (16,241 of 25,500 integer values differ). polymerase-tm's Q5-SDM default (50 mM Na⁺, 2 mM Mg²⁺) falls in this regime: in an ad-hoc check on the bulk sequences (4,926 non-palindromic) it differed from the published equation by −1.90 to +2.39 °C (mean +0.04 °C). NEB's Tm calculator and API do not use this correction, so NEB cannot arbitrate.
8. **Biopython symmetry correction.** By default (`selfcomp=False`) Biopython applies no symmetry term, and it agrees with tm.lua for self-complementary sequences too (456 raw values, max |Δ| 1.7e-13 °C). With `selfcomp=True` it adds ΔS_sym = −1.4 e.u. (DNA_NN3) and uses C rather than C/4 (here dnac2 = 0, so the concentration term is the same). Biopython is then lower by 0.86 °C on average (max 2.30 °C) over 456 palindromic cases. NEB and polymerase-tm apply no symmetry term, and neither does tm.lua; primers are almost never self-complementary.

## Deviations

- Default behaviour is NEB's API, not polymerase-tm: four buffer salts and the Ta rounding procedure differ (findings 2–4). Exact polymerase-tm behaviour is opt-in via `compat = "polymerase-tm"`, an option the task did not list.
- `method = "owczarzy2008"` implements the published equation and therefore differs from polymerase-tm in the mixed regime (finding 7). Default Mg²⁺ is 2 mM.
- NEB's uncapped Ta for Crimson Taq, Multiplex and Q5U is not adopted (finding 5).
- No NEB contact email was sent. The host email lookup was still awaiting approval after ~25 min, and the parameter is optional.
- `M.ta` also returns `info.ta_decimal`; `tm_detail` also returns `conc_eff_nM`, `mg_mM`, `dmso` and `compat`. These are extra fields; no listed names changed.
- The fixture has 934 cases, more than "a few hundred".
